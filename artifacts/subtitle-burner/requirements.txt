# NOT a dependency, deliberately: `imageio-ffmpeg`.
#
# app.py prefers its bundled ffmpeg binary when present, but the system
# ffmpeg is the supported one -- on Replit that is replit.nix's
# `pkgs.ffmpeg-full`, which has libass (the subtitles filter) and, being part
# of the image, cannot be pruned by a dependency sync. The pip binary can be,
# and was: it went missing under a running server and every render failed on
# spawn until the resolution was taught to check the path and re-resolve.
#
# So do not add it here expecting it to be required, and do not remove the
# preference in app.py expecting it to be dead -- it is the fallback for
# environments with no system ffmpeg at all.

# Tighter word timestamps. Whisper infers word times from decoder attention and
# they drift; WhisperX aligns them against a phoneme model, and every caption

# timings whenever the import, the model load or the alignment fails.
#
# Deliberately NOT in pyproject.toml: it pulls torch (~2-3 GB), and a deploy
# that builds from pyproject stays lean without it.
